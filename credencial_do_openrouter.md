# Credenciais do OpenRouter

O AnotaAI usa a chave de API do OpenRouter para gerar material de estudo. Gere as credenciais nos painéis oficiais e configure as variáveis no processo que inicia o backend.

## Chave do OpenRouter

1. **Abra a página de chaves:** Entre no painel do OpenRouter (https://openrouter.ai/), acesse sua conta, acesse **API Keys** e escolha **Create API Key**.

2. **Identifique a chave:** Crie um nome como `AnotaAI` e, se quiser controlar os gastos, configure um limite de créditos e o período de renovação da chave.

3. **Copie a chave gerada:** Salve a chave gerada e configure `OPENROUTER_API_KEY`. O painel exibe o valor completo apenas na criação.
